# EOD Update Application

### Description 
This is a Node.js , Express.js and Typescript backend for EOD (End of the day) Application and integrated with Firebase database to store the Eod Updates.

- Typescript
- Node.Js
- Express 
- Firestore Database

###  Get Started:
### Steps:

1. Clone this project to your computer:
   ```
   git clone https://github.com/shaik-mahammad-rafi01/eod-update-app-backend.git
   ```
2. Open the folder:
   ```
   cd eod-update-app-backend
   ```
3. Install dependencies:
   ```
   npm install
   ```

4. compile the app:
   ```
   npm run build
   ```
   
4. Run the app: 
   ```
   npm start
   ```
